SALON MANAGEMENT SYSTEM
A desktop application for managing salon operations: customers, services, appointments, and billing.
Repository: https://github.com/Urwaabid10/Salon-Management-System-Visual-prog.git

FEATURES

Customer Management - Add, view, update, delete, search customers
Service Management - Create services with dynamic pricing
Appointment Booking - Schedule appointments with date/time
Billing System - Generate invoices and track payments
Security - User authentication and role-based access


TECHNOLOGY STACK
Language:           C#
Framework:          .NET 4.7.2+
Database:           MySQL 8.0+
UI Framework:       Windows Forms
Operating System:   Windows 7+

INSTALLATION

Install Prerequisites

Visual Studio Community

MySQL Server 8.0+


Create Database

Configure Connection String
Edit Salon system/Database/DBConnection.cs
Build and Run
